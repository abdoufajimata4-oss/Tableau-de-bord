## Dashboard de gestion des commandes d'un site de vente de vêtement appelé Fatou

# Description

Ce projet est un tableau de bord web en HTML, CSS et JavaScript permettant de visualiser les commandes récentes, les clients
les plus actifs et un menu latéral de navigation. Il s'agit d'un interface d’administration vitrine suivant l’activité d’une 
boutique en ligne de vêtements et d’accessoires.

# Aperçu

Le Dashboard affiche :
- un menu latéral avec navigation ;
- un tableau des commandes récentes ;
- des cartes des meilleurs clients ;
- une interface simple, claire et responsive selon le style CSS utilisé.

# Fonctionnalités

- Affichage des commandes récentes dans un tableau.
- Visualisation des informations client, paiement, statut et livraison.
- Mise en avant des meilleurs clients.
- Menu latéral avec icônes Materials Symboles.
- Structure adaptée à une future extension avec d’autres pages comme utilisateurs, messagerie et statistiques.

# Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Google Materials Symboles
- Structure multipages

# Objectif du projet

Ce projet a pour but d'illustrer une interface d’administration simple pour la gestion des commandes d’une boutique en ligne.
Il peut être utilisé comme base pour un système plus complet de suivi des ventes, des utilisateurs et des statistiques.
